# 公开验证说明

## 本地离线验证

执行：`python -m unittest discover -s tests -v`。测试不读取开发者的密钥文件，不调用真实模型。

覆盖：

- 全部规格、配料与整数计价；数量边界、增删改、清空和失败输入不改变购物车。
- LangGraph 循环、缺规格、歧义对象、未知行、非法数量、工具异常、调用轮数与请求上限。
- 控件与聊天共享购物车、页面会话隔离、新对话重置、等待/错误提示。
- SDK + 本地 MockTransport：Responses 与 Chat Completions 参数、调用 ID 配对、结果回传、截断拒绝、用量缺失、脱敏、限流、有限重试与付费阻断。
- 无环境配置时默认模拟模式，页面创建与启动不请求真实 API。

发布时实际测试数量和结果见 [发布检查](PUBLICATION.md)。本机验证环境为 Python 3.13、Panel 1.10、LangGraph 1.2、OpenAI SDK 2.54；依赖范围不是跨版本完整认证或锁定文件。

## 已执行的真实模型验收

仅使用智谱标准 API 的 `glm-4.7-flash`，非模拟替身：

1. 模型调用 `query_menu`，查询汉堡各规格与价格，购物车不变。
2. 模型调用 `add_item`，添加一份小份汉堡、无配料、数量 1。
3. 页面、业务回执及工具记录一致：单价/小计/总计 **7.00 EUR**。

该成功会话收到 4 次模型完成响应；最初曾遇到 20 秒超时，临时延长至 60 秒后通过。没有充值、购买套餐、切换收费模型，未声称客户端记录等于独立账单审计。

[真实验收截图](images/real-glm-menu-cart.jpg)已人工检查，不含密钥、账号资料或认证请求头。

## 仍待验证

真实模型的规格追问、上下文补全、同款不同配料、多轮修改、歧义澄清、删除及复杂中文理解，尚未完成真实验收。对应的业务函数和模拟流程测试通过，不等于真实模型能力通过。

真实 OpenAI Responses 服务、长时间稳定性、多浏览器、多用户负载、跨平台安装、订单持久化与生产部署均未验收。业务字段合法，也不保证模型正确理解用户意图。
