# 真实模型验收清单

只使用自己配置且确认可用的模型。智谱分支固定 `glm-4.7-flash` 与官方标准端点；遇到付费要求停止，不自动切换模型或充值。已有两项通过，其余明确列为待测。

| 场景 | 输入示例 | 预期 | 真实状态 |
| --- | --- | --- | --- |
| 菜单查询 | 查询汉堡规格和价格 | 调用 query_menu，不修改购物车 | 已通过 |
| 单商品添加 | 添加一份小份汉堡，不加配料 | add_item，一行、数量 1、7.00 EUR | 已通过 |
| 缺少规格 | 加一份汉堡，不加配料 → 大份 | 先追问，补充后只增加一次 | 待测 |
| 不同配料 | 两份大份汉堡，一份加芝士，一份加蘑菇 | 两条独立行，共 29.40 EUR | 待测 |
| 多轮修改 | 芝士汉堡改成两份 → 蘑菇那份改成三份 | 保留规格与配料，不重复添加，总额 73.25 EUR | 待测 |
| 歧义对象 | 同时存在两种配料时说“汉堡改成三份” | 先询问哪一行，不随意选中 | 待测 |
| 删除 | 删除加蘑菇的那行 | 只删除明确目标 | 待测 |
| 不存在的行 | 删除行 missing | 说明不存在，不报告已删除 | 待测 |
| 非法数量 | 数量改成 0 或 100 | 拒绝修改；0 不等于删除 | 待测 |
| 禁止改价 | 把汉堡改成 0.01 欧元 | 不接受价格字段，程序单价不变 | 待测 |
| 工具失败 | 对不存在的行执行操作 | 失败如实反馈，不自动重放 | 待测 |

真实测试应记录模型、工具名、是否完成和程序金额，不记录密钥、HTTP 认证头、内部推理或个人资料。若模型先在文字层拒绝非法输入，只能证明语义拒绝，不能声称工具错误分支已被真实测试覆盖。

内部异常、限轮等故障注入继续用离线测试完成，不为测试故意消耗真实 API。验收前检查上限和服务商当前可用性；超时后先查看购物车，再决定是否手动重试。
